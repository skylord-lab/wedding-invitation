## Preview
Extract the ZIP and open `index.html` in a browser. Tap **Open invitation** to navigate to `invitation.html`.

## Publish free with GitHub Pages
1. Create a GitHub repository and upload `index.html`, `invitation.html`, and `README.md` to the repository root.
2. Open **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. After deployment, share the published URL.

The background photograph and fonts are loaded from external services, so internet access is needed for those design assets.
