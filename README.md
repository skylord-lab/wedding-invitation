# Srikanth & Shreya — Cinematic Wedding Invitation

## Included
- Separate welcome page and invitation page (`index.html` → `invitation.html`)
- Wedding and reception countdowns (India Standard Time)
- Tap-to-play original synthesized ambient background music (no copyrighted song file)
- Three sample gallery images; replace with the couple's own photos before publishing
- Google Maps search links for both venues
- Responsive mobile layout

## Add the couple's real photos
In `invitation.html`, find the `<div class="photos">` gallery. Replace each sample image URL in an `<img src="...">` with the filename of your photo, for example `photos/couple-1.jpg`. Create a `photos` folder in the same repository and upload the images there.

## Preview
Open `index.html` in a browser and tap Open Invitation. An internet connection is needed for Google Fonts and sample photos.

## Publish free with GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `invitation.html`, and `README.md` to your GitHub repository root (plus your own photos folder if added).
3. Open Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/ (root)`, then Save.
5. Share the published GitHub Pages URL.
